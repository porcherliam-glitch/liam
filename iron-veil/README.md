# OPERATION IRON VEIL

Ein Zombie-Extraction-Shooter in der Ego-Perspektive, der komplett im Browser läuft. Die Sperrzone 7 ist gefallen: Infizierte ziehen durch die Straßen, Söldnertrupps plündern, was übrig ist. Sie gehen mit Ihrer Ausrüstung hinein, plündern, überleben und müssen lebend wieder heraus. Mit der Beute bauen Sie Ihre Basis aus – bevor die Toten an Ihr Tor klopfen.

Alles wird im Browser erzeugt: 3D-Grafik, Texturen und Geräusche. Es wird nichts aus dem Internet geladen und nichts installiert.

> **Achtung, brutale Gewalt:** Das Spiel zeigt viel Blut, abgetrennte Gliedmaßen und platzende Köpfe. In den Einstellungen lässt sich Gore auf „Normal“ (Blut ohne Zerstückelung) oder „Aus“ stellen.

## Spielen

**Am einfachsten:** Die Datei `OperationIronVeil.html` in diesem Ordner doppelklicken. Sie öffnet sich im Browser (Chrome, Edge oder Firefox empfohlen).

Der Spielstand liegt im Browser (localStorage). Mit einem anderen Browser oder nach dem Löschen der Browserdaten beginnt eine neue Truppe. Alte Spielstände (v2/v3) werden automatisch übernommen.

In den Menüs funktionieren Maus, Tastatur und Controller (Steuerkreuz, A = auswählen, B = zurück).

## So läuft es

1. **Basis.** Sie laufen durch Ihre Basis und drücken **E** an den Stationen: Händler, Lager, Funk, Werkbank, Waffenwerkstatt, Bauplätze. Alles ist auch über das Hauptmenü erreichbar.
2. **Ausrüsten und packen.** Im Lager Waffen, Weste, Helm und Rucksack anlegen und den Rucksack packen: Munition, Verbände, Essen, Wasser, Granaten. **Schnell packen** macht das automatisch. Der **sichere Behälter** bleibt auch beim Tod erhalten.
3. **Einsatz planen (Funk).** Aufträge annehmen, Einstiegspunkt und Tageszeit wählen. Nachts sieht man wenig, es gibt mehr Infizierte – aber bessere Beute.
4. **In der Zone.** Behälter durchsuchen (Schränke, Kühlschränke, Werkzeugkästen, Waffenkoffer, Tresore …), Gefallene durchsuchen, Versorgungsabwürfe sichern. Schüsse locken Horden an; das Messer ist leise. Achten Sie auf **Blutungen**, **Hunger**, **Durst**, **Infektion** (Bisse) und das **Gewicht** im Rucksack.
5. **Raus.** Nur wer eine Extraktion erreicht, behält die Beute. Pro Einsatz sind nur einige Ausgänge offen. Der Hubschrauber muss gerufen und der Landeplatz gehalten werden; das Boot braucht Treibstoff, der Tunnel einen Schlüssel, der Grenzposten Bestechungsgeld.
6. **Ausbauen.** Beute verkaufen, Gebäude bauen, Personal einteilen (Munition, Medizin und Essen werden laufend hergestellt), forschen, Aufsätze montieren.
7. **Verteidigen.** Jeder Einsatz und jede Stunde macht die Infizierten auf die Basis aufmerksam. Ab 60 % Bedrohung greifen sie an: selbst verteidigen (3 Wellen) oder den Wachen überlassen.

Wer stirbt, abbricht, die Seite neu lädt oder zu lange braucht, verliert alles Mitgenommene außer dem sicheren Behälter.

## Inhalt

- **Riesige Sperrzone** (~600 × 600 m) mit Stadtteilen: Altstadt, Industriegebiet, Hafen, Militäranlage, Forschungslabor mit Endgegner, Bauernhof, Bahnhof, Nordwald, Steinbruch. Vier Tageszeiten.
- **Infizierte**: Schlurfer, Läufer, Brecher, Schreier, Spucker, Schleicher, Kriecher und der Koloss. Dazu **Söldnertrupps** mit Deckung, Flanken und Scharfschützen.
- **Gore**: Kopftreffer lassen Köpfe platzen, Klingen und Schrot trennen Arme und Beine ab, Explosionen zerreißen Körper; Blut an Wänden, auf dem Boden und auf dem Bildschirm.
- **15 Waffen**: Messer, Machete, Feuerwehraxt, P9, R-44 Revolver, VX-9 und K5 Maschinenpistolen, MK-4, SR-74, BR-10, KV-12 Pump- und SG-8 Selbstladeflinte, DR-7 Präzisionsgewehr, Falke .338 Repetierer, LM-60 MG.
- **9 Aufsätze**: Rotpunkt, Holo-Visier, 4×-Zielfernrohr, Schalldämpfer, Kompensator, zwei Griffe, erweitertes Magazin, Laser-Licht-Modul. **9 Munitionssorten** inklusive panzerbrechender Munition und Flintenlaufgeschossen.
- **Überleben**: Gesundheit, Blutungen, Hunger, Durst, Infektion, Schmerzmittel, Stimulanzien, Tragegewicht.
- **Basis**: 13 Gebäude mit je bis zu 3 Stufen, Personal, Herstellung (Medizin, Granaten, Westen, Rucksäcke, Munition, Aufsätze), 9 Forschungen, Aufträge über Funk, Angriffe auf die Basis.
- **Einstellungen**: Maus- und Zielempfindlichkeit, Sichtfeld, Lautstärke, Gore, Schwierigkeit, Grafikqualität, Bildschirmwackeln, Bildrate.

## Für Entwickler

Voraussetzung: Node.js 20 oder neuer.

```bash
npm install
npm run dev          # Entwicklungsserver mit automatischem Neuladen
npm run build        # Prüft Typen, baut dist/ und die Einzeldatei OperationIronVeil.html
npm test             # Logik-Tests (Vitest)
npm run verify:all   # Browser-Tests mit Playwright (vorher bauen)
```

Prüfstände (nur mit `npm run dev`): `dev.html` (Zone, Basis und Gegner ohne Spiel), `dev-ai.html` (Söldner), `dev-zombies.html` (Infizierte und Horden), `dev-gore.html` (Gore), `dev-weapons.html` (Waffen in der Hand, Symbole, Weltmodelle), `dev-props.html` (Beute-Behälter, Versorgungsabwurf, Rucksack, Wurfwaffen), `dev-audio.html` (alle Geräusche).
