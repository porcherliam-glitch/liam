# =============================================================================
# Unity-6-Whitelist des Harness
# =============================================================================
# Der Harness kompiliert gegen Unity-2021.3-Referenzen (UnityEngine.Modules 2021.3.33)
# und UnityEditor 2021.1.14 - neuere sind auf nuget.org nicht verfuegbar. APIs, die erst
# ab Unity 2022/2023/6 existieren, werden auf drei Wegen behandelt:
#
#   shim    eigenstaendiger Typ in shims/ (C#-Quelltext, z. B. UnityEngine.Awaitable)
#   patch   fehlender Member eines bestehenden Unity-Typs; RefPatcher fuegt ihn aus
#           patches/Unity6Patches in die Referenz-DLLs ein (nur Signatur)
#   filter  nichts davon - der Compilerfehler wird nur aus der Zaehlung gefiltert und
#           separat aufgelistet. Achtung: die Assembly wird dann trotzdem NICHT gebaut,
#           abhaengige Assemblies/Tests melden Folgefehler. Besser shim/patch ergaenzen.
#
# Format (eine Zeile je API):
#   FEHLERCODE[,FEHLERCODE] | SYMBOL | MECHANISMUS | BEGRUENDUNG
#   - FEHLERCODE: Code(s), die der Compiler OHNE Shim/Patch meldet (wichtig fuer --no-patch)
#   - SYMBOL: Bezeichner, wie er in der Fehlermeldung bzw. im Code steht (ganzes Wort)
#   - shim/patch-Eintraege listet die Zusammenfassung zusaetzlich mit Fundstellen im Code,
#     weil ihr Verhalten nur in Unity 6.3 pruefbar ist.
# =============================================================================

# --- Async (Unity 2023.1+ / 6000.x) -----------------------------------------------
CS0246,CS0103,CS0234 | Awaitable | shim | UnityEngine.Awaitable / Awaitable<T> gibt es erst ab Unity 2023.1 (Async-Standard laut Architektur 1.3, A34). Shim: kein Player-Loop, NextFrame/FixedUpdate/EndOfFrame schliessen sofort ab, doppeltes await wirft.
CS0246,CS0103 | AwaitableCompletionSource | shim | Unity 2023.1+. Shim mit gleicher Oberflaeche.
CS0246 | MainThreadAwaitable | shim | Rueckgabetyp von Awaitable.MainThreadAsync() (Unity 2023.1+). Shim: kein Threadwechsel.
CS0246 | BackgroundThreadAwaitable | shim | Rueckgabetyp von Awaitable.BackgroundThreadAsync() (Unity 2023.1+). Shim: Thread-Pool.
CS4036,CS1061 | GetAwaiter | filter | await auf AsyncOperation/UnityEvent (Unity 2023.1+: AsyncOperationAwaitableExtensions, UnityEventAwaitableExtensions) - im Harness per Shim vorhanden; Eintrag nur fuer --no-patch.
